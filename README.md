Kurd Drama

Kurd Drama is a Kurdish drama streaming application designed to provide users with an easy and organized way to discover and watch Kurdish drama series and episodes.

Features

- Kurdish drama series
- Episodes and video content
- Simple and modern interface
- Drama details and episode information
- Easy navigation
- Kurdish-language entertainment content

Purpose

The goal of Kurd Drama is to bring Kurdish drama content together in one simple and accessible application for Kurdish viewers around the world.

Platform

Kurd Drama is being developed for mobile devices, with the goal of making the application available on iOS and Android.

Status

🚧 Currently in development.

License

This project is intended for the Kurd Drama application.
